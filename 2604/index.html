왜 노트북LM인가

일반 LLM은 웹 검색에 기대다 보니 할루시네이션이 생긴다. 노트북LM은 RAG 방식으로 사용자가 지정한 소스 안에서만 답해 할루시네이션이 줄어든다 — 오픈북 시험 환경에 가깝다.

소스 한도: 무료 50개 · 유료 300개. PDF·웹페이지·구글 드라이브·유튜브 다 입력 가능.

핵심 워크플로우

  1. 노트북 생성 → 소스 추가
  2. Gemini 3.1 Flash로 대화하며 정제
  3. 스튜디오에서 산출물(보고서·마인드맵·오디오·동영상·슬라이드·퀴즈·데이터 테이블) 생성
  4. 메모 순환: 대화 결과를 메모로 저장 → 다시 소스로 변환해서 자료 보강

소스 정제 팁

  • 북마크 URL은 일괄 붙여넣기로 한 번에 추가
  • 키워드만 주면 AI가 검색해 옴 — Fast Research(50개)·Deep Research(300개)
  • "신뢰도 점수 매겨줘"로 가비지 소스 솎아내기
  • 신규 자동 라벨링 버튼으로 소스를 기능·비용·성능 등으로 분류

슬라이드, 진짜 핵심은 커스터마이징

기본 생성 슬라이드는 베이지·회색 파스텔에 모눈 배경 — 한눈에 "노트북LM 티"가 난다. 크롬 확장으로 옷을 입히자.

  • Banana NL — 칠판·픽셀·미니어처·만화 등 스타일 선택
  • 한국 기업 스타일 (최봉우 매니저 직접 제작) — 삼성·SK·LG·현대차·KB금융·네이버 컬러로 자동 생성

목차 고정 팁: "목차 짜줘" → 메모로 저장 → 소스로 변환 → 슬라이드 생성. 순서 흔들림 방지.

만들어진 슬라이드 수정하기

슬라이드는 사실 Nano Banana로 만든 이미지라 원래는 편집이 어려웠다.

  • 부분 재생성 — 슬라이드를 지목하고 "이 문구 빼줘" 식으로 지시 (디자인은 약간 흔들릴 수 있음)
  • PPT 다운로드 + PowerPoint 그림 편집 → 텍스트 편집 — OCR로 이미지 속 텍스트를 뽑아내 직접 수정

오늘의 실습 미션

각자 관심 주제로 자료를 모아 노트북LM에 넣고, 원하는 스타일로 PPT 제작 → 단톡방 공유. 스타일·주제 모두 자유. 아래 카드들이 그 결과물입니다.
